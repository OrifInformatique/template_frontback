=== 2.4 Azure (OAuth2) Login
The Azure login is a redirect dance between the frontend, this backend, spring-auth and Azure
(same paths as spring-auth's OAuth2 endpoints):

. `GET /oauth2/login/azure` redirects the browser (`302`) to spring-auth's Azure login, with
  `/oauth2/callback` as the URL to come back to (`AFTER_OAUTH2_LOGIN_URL`).
. After the Azure login, spring-auth redirects the browser to `GET /oauth2/callback` with a
  temporary auth code; the backend exchanges it for the user and its tokens, keeps them in the
  HTTP session and redirects the browser to the frontend (`AFTER_OAUTH2_LOGIN_FRONTEND_CALLBACK`).
. The frontend calls `POST /oauth2/token` (with the session cookie) and gets the user with its
  access token, and the refresh token in a cookie. Single use: a second call answers `401`.
